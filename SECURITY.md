# Security Policy

Report vulnerabilities through GitHub private vulnerability reporting. Do not open a public issue for findings that could expose chat data, contacts, media, or browser-session state.

Useful reports include reproducible issues involving unintended data transmission, unsafe HTML/CSV output, userscript update integrity, or access to chats beyond the signed-in user's own WhatsApp Web session.

Purr WA Export is an independent open-source utility and is not affiliated with WhatsApp or Meta.
